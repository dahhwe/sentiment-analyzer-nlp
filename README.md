# Практическая работа №1: Анализатор тональности текстов на русском языке

Проект реализует конвейер обработки естественного языка (NLP) для русского языка, включающий токенизацию, полную
нормализацию словаря и классификацию тональности на основе Наивного Байесовского классификатора (Multinomial Naive
Bayes).

## 1. Соответствие требованиям ТЗ и структура конвейера

### 1.1 Токенизатор (`src/tokenizer.py`)

Реализован собственный токенизатор на базе регулярных выражений (`RegexTokenizer`), корректно обрабатывающий кириллицу и
дефисные слова (например, «по-настоящему»), очищая текст от знаков препинания и спецсимволов.

### 1.2 Нормализация словаря (`src/normalizer.py`)

- **Стоп-слова** — удаление общеупотребительных русских стоп-слов, не несущих смысловой и эмоциональной нагрузки.
- **Лемматизация** — приведение слов к начальной словарной форме.
- **Стемминг** — выделение основы слова через суффиксальное отсечение (опциональный модуль).
- **Синонимия** — модуль канонизации синонимических рядов (например, «великолепный», «превосходный», «шикарный» →
  «хороший»), уменьшающий разреженность матрицы признаков.

### 1.3 Классификатор тональности (`src/classifier.py`)

Построен классификатор на базе Multinomial Naive Bayes с векторизацией признаков (Bag-of-Words), вычисляющий
апостериорные вероятности принадлежности текста к классам `positive` и `negative`.

## 2. Обоснование используемых библиотек

- **pymorphy3** — современный морфологический анализатор для русского языка. Выбран за высокую точность лемматизации и
  учёт контекста падежных/родовых окончаний русской морфологии.
- **nltk** — стандартная библиотека компьютерной лингвистики. Использован готовый верифицированный список русских
  стоп-слов (`nltk.corpus.stopwords`) и алгоритмический русский стеммер (`SnowballStemmer`).
- **scikit-learn** — академический и индустриальный стандарт машинного обучения. Использован модуль `MultinomialNB` и
  `CountVectorizer` для построения математически строгого наивного байесовского классификатора.
- **pandas** — легковесный инструмент для загрузки и структурирования текстового датасета из CSV.

## 3. Установка и запуск

### Требования

- Python 3.9+
- Git

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/dahhwe/sentiment-analyzer-nlp.git
cd sentiment-analyzer-nlp
```

### Шаг 2. Создание и активация виртуального окружения

```bash
# Linux / macOS:
python3 -m venv venv
source venv/bin/activate

# Windows:
python -m venv venv
venv\Scripts\activate
```

### Шаг 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## 4. Примеры использования

### А. Пакетная проверка пользовательской фразы через аргументы командной строки

```bash
python main.py --text "Этот спектакль просто потрясающий, великолепная игра актеров!"
```

Вывод:

```

Модель Наивного Байеса успешно обучена на нормализованном корпусе.
Accuracy: 1.00

--- Результат анализа ---
Исходный текст:      Этот спектакль просто потрясающий, великолепная игра актеров!
Токены:              ['этот', 'спектакль', 'просто', 'потрясающий', 'великолепная', 'игра', 'актеров']
После нормализации:  ['спектакль', 'потрясающий', 'хороший', 'игра', 'актёр']
Тональность:         Позитивный 😊
Уверенность:         96.4%
```

```bash
python main.py --text "Ужасный сервис, официант хамит, больше сюда не приду"
```

Вывод:

```

Тональность:         Негативный 😞
```

### Б. Запуск в интерактивном консольном режиме

```bash
python main.py
```

Программа обучит модель на корпусе и предложит вводить фразы в бесконечном цикле. Для выхода введите `exit`.

# Практическая работа №1: Анализатор тональности текстов на русском языке

Проект реализует конвейер обработки естественного языка (NLP) для русского языка, включающий кастомную токенизацию,
полную нормализацию словаря и трехклассовую классификацию тональности (`positive`, `negative`, `neutral`) на основе
Наивного Байесовского классификатора (Multinomial Naive Bayes).

## 1. Соответствие требованиям ТЗ и структура конвейера

### 1.1 Обучающий датасет

В качестве корпуса документов используется открытый русскоязычный датасет *
*[`MonoHime/ru_sentiment_dataset`](https://huggingface.co/datasets/MonoHime/ru_sentiment_dataset)** с Hugging Face:

- **Общий объем**: более 211 000 размеченных текстов (отзывы, новости, социальные сети, бытовая речь).
- **Разметка классов**:
    - `0` → `neutral` (нейтральные факты, новости, бытовые ситуации)
    - `1` → `positive` (положительная эмоциональная окраска)
    - `2` → `negative` (отрицательная эмоциональная окраска)
- **Используемая выборка**: для баланса скорости обучения и полноты словаря скрипт `src/download_dataset.py` формирует
  сбалансированную выборку из 6 000 текстов (по 2 000 на каждый класс), что охватывает свыше 20 000 уникальных русских
  лемм.

### 1.2 Токенизатор (`src/tokenizer.py`)

Реализован собственный токенизатор на базе регулярных выражений (`RegexTokenizer`), корректно обрабатывающий кириллицу и
составные слова через дефис (например, «по-настоящему»), попутно очищая текст от пунктуации и мусорных символов.

### 1.3 Нормализация словаря (`src/normalizer.py`)

- **Стоп-слова** — удаление общеупотребительных русских служебных частей речи (союзы, предлоги, частицы), не несущих
  смысловой и эмоциональной нагрузки.
- **Лемматизация** — приведение слов к нормальной словарной форме с учетом контекста русской морфологии.
- **Стемминг** — выделение основы слова путем суффиксального отсечения (алгоритм Snowball).
- **Синонимия** — модуль канонизации синонимических рядов (например, «великолепный», «превосходный», «шикарный» →
  «хороший»), уменьшающий разреженность матрицы признаков.

### 1.4 Классификатор тональности (`src/classifier.py`)

Построена трехклассовая модель **Multinomial Naive Bayes** с мешком слов (Bag-of-Words). Реализован перехват
Out-Of-Vocabulary (OOV) и пограничных вероятностей: если эмоциональные маркеры в предложении отсутствуют, текст
классифицируется как нейтральный (`neutral 😐`), что предотвращает ложные срабатывания на фактологических и бытовых
фразах.

## 2. Обоснование используемых библиотек

- **datasets (Hugging Face)** — стандарт для потоковой загрузки верифицированных NLP-датасетов. Позволяет загружать
  размеченный корпус напрямую без необходимости хранить тяжелые бинарные архивы внутри Git-репозитория.
- **pymorphy3** — современный морфологический анализатор для русского языка. Выбран за высокую точность лемматизации и
  учёт контекста падежных/родовых окончаний русской морфологии.
- **nltk** — стандартная библиотека компьютерной лингвистики. Использован готовый верифицированный список русских
  стоп-слов (`nltk.corpus.stopwords`) и алгоритмический русский стеммер (`SnowballStemmer`).
- **scikit-learn** — академический и индустриальный стандарт машинного обучения. Использованы модули `MultinomialNB` и
  `CountVectorizer` для построения математически строгого наивного байесовского классификатора.
- **pandas** — легковесный инструмент для загрузки, балансировки и структурирования текстового корпуса.

## 3. Установка и запуск

### Требования

- Python 3.9+
- Git

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/dahhwe/sentiment-analyzer-nlp.git
cd sentiment-analyzer-nlp/pr1
```

### Шаг 2. Создание и активация виртуального окружения

```bash
# Linux / macOS:
python3 -m venv venv
source venv/bin/activate

# Windows:
python -m venv venv
venv\Scripts\activate
```

### Шаг 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 4. Подготовка датасета (при первом запуске)

Если файл `data/dataset.csv` отсутствует, запустите загрузчик корпуса:

```bash
python src/download_dataset.py
```

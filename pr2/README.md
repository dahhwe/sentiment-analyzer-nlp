# Практическая работа №2: Семантический анализатор текстов на основе LSA

Проект реализует прототип семантического анализатора естественного языка на основе латентно-семантического анализа
(Latent Semantic Analysis, LSA). Используются результаты [Практической работы №1](../pr1): токенизатор, нормализатор
словаря, размеченный корпус и классификатор тональности. Анализатор строит векторы TF-IDF, переводит их в векторы тем,
выполняет стиринг по меткам тональности, ищет документы по смыслу и сравнивает тексты между собой.

## 1. Соответствие требованиям ТЗ и структура конвейера

### 1.1 Использование результатов ПР1

- **Токенизация и нормализация** – классы `RegexTokenizer` и `TextNormalizer` импортируются из `../pr1/src`
  (стоп-слова, лемматизация, связывание отрицаний, канонизация синонимов).
- **Корпус** – датасет из ПР1 `../pr1/data/dataset.csv` (6 000 текстов, классы `positive`, `negative`, `neutral`).
  Нормализованный корпус берется из кэша ПР1 `cached_dataset.csv`; если кэша нет, он строится заново тем же конвейером.
- **Классификатор** – наивный Байес из ПР1 используется для сравнения точности со стирингом.

### 1.2 Векторы TF-IDF (`src/lsa.py`)

Матрица «документ – терм» строится через `TfidfVectorizer` по уже нормализованным текстам. Используется
логарифмическая частота терма (`sublinear_tf`), отбрасываются слишком редкие (меньше 2 документов) и слишком частые
(больше половины документов) слова. Дополнительно убираются служебные леммы («который», «весь», «свой»), которые
в ПР1 проходят фильтр стоп-слов, так как он применяется до лемматизации.

### 1.3 Векторы тем — LSA (`src/lsa.py`)

Матрица TF-IDF раскладывается усеченным сингулярным разложением (`TruncatedSVD`) на 100 тем. Каждый документ
представляется вектором тем, нормированным по длине, поэтому косинусное сходство считается скалярным произведением.
Для каждой темы можно вывести слова с наибольшим весом.

### 1.4 Стиринг (`src/steering.py`)

Темы LSA строятся без учителя и описывают, о чем текст (отели, врачи, автомобили), а не его тональность. Линейный
дискриминантный анализ (LDA), обученный на метках тональности из ПР1, находит комбинации тем, лучше всего разделяющие
классы, и определяет тональность нового текста по его вектору тем.

### 1.5 Семантический поиск и сравнение текстов

- **Поиск** – документы корпуса ранжируются по косинусному сходству их векторов тем с вектором тем запроса, поэтому
  находятся тексты, близкие по смыслу, даже без общих слов с запросом.
- **Сравнение** – для двух текстов выводится косинусное сходство в пространстве TF-IDF и в пространстве тем LSA.

## 2. Обоснование используемых библиотек

- **scikit-learn** – `TfidfVectorizer` для векторов TF-IDF, `TruncatedSVD` для LSA (работает с разреженными
  матрицами без перевода в плотные), `LinearDiscriminantAnalysis` для стиринга.
- **numpy** – операции с векторами тем (скалярные произведения, сортировка результатов).
- **pandas** – загрузка корпуса и кэша нормализации.
- **pymorphy3, nltk** – используются модулями нормализации из ПР1.

## 3. Установка и запуск

### Требования

- Python 3.9–3.12 (как и в ПР1, из-за версии scikit-learn 1.4.2)
- Git

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/dahhwe/sentiment-analyzer-nlp.git
cd sentiment-analyzer-nlp/pr2
```

### Шаг 2. Создание и активация виртуального окружения

```bash
# Linux / macOS:
python3 -m venv venv
source venv/bin/activate

# Windows:
python -m venv venv
venv\Scripts\activate
```

### Шаг 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Датасет уже лежит в `../pr1/data/dataset.csv`. При первом запуске корпус нормализуется (около 10 секунд), результат
сохраняется в кэш ПР1, и следующие запуски проходят быстрее.

### Г. Пользовательские данные

Вместо корпуса ПР1 можно передать свой файл через `--data`: TXT (один документ на строку) или CSV со столбцом `text`
(если есть столбец `label`, по нему обучается стиринг). Пример — `data/user_corpus.txt`, 50 текстов на 5 тем
(программирование, кулинария, футбол, космос, огород):

```bash
python main.py --data data/user_corpus.txt --n-topics 10 --search "испечь пирог в печи"
```

Вывод:

```text

   3. (0.96) Курицу замаринуйте в соусе из чеснока, мёда и соевого соуса, затем запеките в духовке.
   4. (0.67) Игрок получил травму на тренировке и пропустит несколько матчей чемпионата.
```

Третий документ не содержит слов запроса, но найден по смыслу (тема кулинарии).

# Практическая работа №3: Семантический анализатор набора документов на основе Word2Vec и Doc2Vec

Проект расширяет семантический анализатор из [Практической работы №2](../../../Users/dahhw/Downloads/sentiment-analyzer-nlp-pr3/sentiment-analyzer-nlp/pr2) для обработки набора документов на
схожесть. Помимо векторов тем LSA из ПР2 используются векторы слов Word2Vec и векторы документов Doc2Vec, обученные на
корпусе из [Практической работы №1](../../../Users/dahhw/Downloads/sentiment-analyzer-nlp-pr3/sentiment-analyzer-nlp/pr1). Для каждой операции (сравнение текстов, поиск, обработка набора документов)
результаты выводятся обоими анализаторами, что позволяет сравнить их между собой. Нейросети классов CNN, RNN и LSTM
не используются: Word2Vec и Doc2Vec обучаются как неглубокие модели с одним скрытым слоем.

## 1. Соответствие требованиям ТЗ и структура конвейера

### 1.1 Использование результатов ПР1 и ПР2

- **Нормализация** – классы `RegexTokenizer` и `TextNormalizer` импортируются из `../pr1/src`.
- **Корпус** – датасет из ПР1 `../pr1/data/dataset.csv` (6 000 текстов) и кэш нормализации `cached_dataset.csv`.
- **Анализатор LSA** – класс `LSAModel` импортируется из `../pr2/src` и обучается на том же корпусе (100 тем).
- **Стиринг** – класс `SentimentSteering` (LDA) из ПР2 используется для сравнения анализаторов по точности.

### 1.2 Векторы слов Word2Vec (`src/word_vectors.py`)

Документы корпуса разбиваются на предложения, каждое предложение нормализуется конвейером ПР1, и на полученных
списках лемм обучается модель `Word2Vec` из библиотеки gensim. Используется подход CBOW (центральное слово окна
предсказывается по окружающим словам) с параметрами из лекции: размерность 100, окно 6 слов, минимальная частота
слова 3, порог прореживания частых слов `1e-3`, 20 эпох. Вариант skip-gram на этом корпусе обучался в 3 раза дольше
(30 секунд против 10) и давал менее точных соседей, поэтому выбран CBOW.

Модель умеет находить близкие слова (`most_similar`), решать задачи на аналогию (`a - b + c`) и находить лишнее слово
в списке (`doesnt_match`). Вектор документа строится как среднее векторов его слов.

### 1.3 Векторы документов Doc2Vec (`src/doc_vectors.py`)

Каждый документ корпуса оборачивается в `TaggedDocument` с тегом, равным его номеру, и обучается модель `Doc2Vec`
(размерность 100, 40 эпох). Выбран вариант PV-DBOW (`dm=0`): по сравнению с PV-DM (`dm=1`) при одинаковых 20 эпохах
он дал более высокую точность стиринга (0.67 против 0.64) и заметно лучший поиск похожих документов. Вектор нового документа выводится
методом `infer_vector` при «замороженных» весах модели.

Обученные модели сохраняются в папку `models` методом `save` и при следующих запусках загружаются методом `load`.

### 1.4 Обработка набора документов (`src/analyzer.py`)

Класс `DocumentAnalyzer` объединяет оба анализатора и строит векторы одним из трех способов: LSA, среднее Word2Vec
или Doc2Vec. Для набора документов пользователя вычисляются:

- **матрица попарного косинусного сходства** документов;
- **самые похожие пары** документов;
- **группы документов**, найденные методом k-средних (`KMeans`) по векторам документов.

Также доступны поиск похожих документов в корпусе и сравнение двух текстов.

## 2. Обоснование используемых библиотек

- **gensim** – реализация Word2Vec и Doc2Vec (`Word2Vec`, `Doc2Vec`, `TaggedDocument`), сохранение и загрузка моделей.
- **scikit-learn** – `KMeans` для группировки документов, а также `TruncatedSVD` и `LinearDiscriminantAnalysis`
  в модулях из ПР2.
- **numpy** – операции с векторами (скалярные произведения, усреднение векторов слов).
- **pandas** – загрузка корпуса и кэша нормализации.
- **pymorphy3, nltk** – используются модулями нормализации из ПР1.

## 3. Установка и запуск

### Требования

- Python 3.9–3.12 (из-за версий scikit-learn 1.4.2 и gensim 4.3.3)
- Git

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/dahhwe/sentiment-analyzer-nlp.git
cd sentiment-analyzer-nlp/pr3
```

### Шаг 2. Создание и активация виртуального окружения

```bash
# Linux / macOS:
python3 -m venv venv
source venv/bin/activate

# Windows:
python -m venv venv
venv\Scripts\activate
```

### Шаг 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Шаг 4. Обучение моделей

```bash
python main.py --train
```

Обучение занимает около минуты и выполняется один раз, дальше модели загружаются из папки `models`. Если пропустить
этот шаг, модели обучатся автоматически при первом запуске любой команды. Word2Vec и Doc2Vec обучаются в несколько
потоков, поэтому после повторного обучения числа и порядок слов в выводе могут немного отличаться от примеров ниже.

## 5. Сравнение анализаторов

| Критерий                       | LSA (ПР2)                                           | Word2Vec / Doc2Vec (ПР3)                                       |
|--------------------------------|-----------------------------------------------------|----------------------------------------------------------------|
| Как строятся векторы           | SVD матрицы TF-IDF, учитывается весь документ        | Обучение на скользящем окне слов (Word2Vec), вектор документа (Doc2Vec) |
| Близкие слова                  | Слова одной темы: «машина» – багажник, руль          | Слова-заменители: «машина» – автомобиль, авто                  |
| Аналогии                       | Не поддерживаются                                   | Работают: официант - ресторан + больница = реанимация, медсестра |
| Тексты без общих слов          | Низкое сходство (0.25)                              | Высокое сходство (0.84 и 0.72)                                 |
| Набор документов `my_docs.txt` | Найдены 3 пары из 4                                 | Doc2Vec нашел все 4 пары                                       |
| Короткие запросы               | Работают хорошо                                     | Doc2Vec ошибается на коротких запросах и коротких документах   |
| Стиринг тональности (Accuracy) | 0.70                                                | 0.68 (Word2Vec), 0.67 (Doc2Vec)                                |
| Обучение                       | Около 3 секунд при каждом запуске                   | Около минуты один раз, модели сохраняются на диск              |

Выводы:

- Word2Vec лучше передает смысл отдельных слов: близкими оказываются синонимы и слова одной роли, работают аналогии.
  LSA объединяет слова, которые встречаются в одних документах, поэтому его «близкие слова» описывают тему.
- Для текстов, написанных разными словами, Word2Vec и Doc2Vec дают намного более высокое сходство, чем LSA. На наборе
  документов пользователя Doc2Vec нашел все пары отзывов на одну тему, LSA пропустил пару «отель» и «гостиница».
- У Doc2Vec сходство даже несвязанных текстов остается около 0.4, поэтому важны не сами значения, а их сравнение
  между собой. На коротких запросах Doc2Vec работает хуже остальных: вектор нового документа выводится по нескольким
  словам и получается неточным.
- Для определения тональности LSA остается немного точнее (0.70 против 0.68 и 0.67) и обучается быстрее.
  Это совпадает с выводом лекции: LSA быстрее обучается и лучше различает длинные документы, а Word2Vec дает более
  точные умозаключения на уровне слов.

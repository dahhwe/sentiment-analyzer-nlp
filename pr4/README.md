# Практическая работа №4: Семантический анализатор корпуса документов на основе сверточной и рекуррентной сетей

Проект расширяет семантический анализатор из [Практической работы №3](../pr3) для обработки корпуса документов.
Каждый документ подается в нейронную сеть как последовательность векторов слов Word2Vec, обученных в ПР3, а сеть
определяет его тональность. Реализованы сверточная сеть (CNN) и рекуррентная сеть (SimpleRNN), их результаты
сравниваются с анализаторами из ПР2 (LSA) и ПР3 (Word2Vec, Doc2Vec). Сети LSTM и модели sequence-to-sequence
не используются.

## 1. Соответствие требованиям ТЗ и структура конвейера

### 1.1 Использование результатов ПР1–ПР3

- **ПР1** – нормализация текста (`RegexTokenizer`, `TextNormalizer`), корпус из 6 000 текстов с метками тональности
  и кэш нормализации.
- **ПР2** – анализатор `LSAModel` и стиринг `SentimentSteering` (LDA).
- **ПР3** – модели Word2Vec и Doc2Vec из папки `../pr3/models` и класс `DocumentAnalyzer`. Векторы Word2Vec служат
  входом для нейросетей вместо предобученной модели Google News из лекции.

Все анализаторы обучаются на одной и той же обучающей выборке (70 % корпуса) и проверяются на одной тестовой (30 %).

### 1.2 Подготовка последовательностей (`src/sequences.py`)

- `tokenize_and_vectorize` – заменяет каждую лемму документа ее вектором Word2Vec (слова вне словаря пропускаются)
  и нормирует векторы по длине.
- `pad_trunc` – приводит документы к длине `maxlen`: длинные усекаются, короткие дополняются нулевыми векторами.

`maxlen = 100` выбран по данным: медианная длина документа 45 слов, полностью в 100 слов помещается 84 % документов.
Размерность векторов слов `embedding_dims = 100`, как у модели Word2Vec из ПР3.

### 1.3 Сверточная сеть (`src/networks.py`, класс `CNNClassifier`)

`Conv1D` (100 фильтров шириной 3 слова, ReLU) → `GlobalMaxPooling1D` → `Dense(100)` → `Dropout(0.5)` → ReLU →
`Dense(3)` → softmax. Каждый фильтр видит три соседних слова, после субдискретизации от него остается одно
максимальное значение, поэтому документ превращается в вектор из 100 признаков. Оптимизатор `adam`.

Число параметров: сверточный слой 100 · (3 · 100) + 100 = 30 100, скрытый слой 100 · 100 + 100 = 10 100,
выходной слой 100 · 3 + 3 = 303, всего 40 503.

### 1.4 Рекуррентная сеть (`src/networks.py`, класс `RNNClassifier`)

`SimpleRNN(50, return_sequences=True)` → `Dropout(0.5)` → `Flatten` → `Dense(3)` → softmax, оптимизатор `rmsprop`, как
в лекции. Каждый из 50 нейронов получает вектор слова (100 весов), смещение и свой выход с прошлого шага (50 весов):
(100 + 1 + 50) · 50 = 7 550 параметров. После `Flatten` получается вектор 100 · 50 = 5 000, выходной слой содержит
5 000 · 3 + 3 = 15 003 параметра:

### 1.5 Обучение и сохранение

`batch_size = 32`, до 15 эпох. 10 % обучающей выборки отводится на проверку, и обратный вызов `EarlyStopping`
останавливает обучение, если точность на проверке не растет 3 эпохи подряд (лучшие веса восстанавливаются).
Тестовая выборка в обучении не участвует. Для повторяемости задается `keras.utils.set_random_seed(1337)`.
Структура сети сохраняется в `models/*.json`, веса в `models/*.weights.h5`.

### 1.6 Обработка корпуса документов

Режим `--corpus` принимает корпус пользователя (TXT-файл с документом на строку или папку с TXT-файлами) и выводит
тональность каждого документа по всем анализаторам и распределение тональности по корпусу.

## 2. Обоснование используемых библиотек

- **TensorFlow / Keras** – построение и обучение сетей (`Sequential`, `Conv1D`, `GlobalMaxPooling1D`, `SimpleRNN`,
  `Dropout`, `EarlyStopping`), сохранение структуры в JSON и весов в HDF5.
- **gensim** – загрузка моделей Word2Vec и Doc2Vec из ПР3.
- **scikit-learn** – разбиение на выборки, а также LSA и LDA в модулях из ПР2.
- **numpy, pandas** – массивы последовательностей и загрузка корпуса.
- **pymorphy3, nltk** – используются модулями нормализации из ПР1.

## 4. Подбор гиперпараметров

Начальные значения взяты из лекций, затем менялись по одному. Accuracy на тестовой выборке:

| Вариант                                                               | Параметров | Accuracy |
|-----------------------------------------------------------------------|------------|----------|
| CNN как в лекции (250 фильтров, Dense 250, Dropout 0.2), без нормировки векторов | 138 753 | 0.63 |
| CNN как в лекции, векторы слов нормированы по длине                   | 138 753    | 0.67     |
| CNN 100 фильтров, Dense 100, Dropout 0.5 (**итоговая**)               | 40 503     | 0.68     |
| SimpleRNN 50, Dropout 0.2 (как в лекции)                              | 22 553     | 0.61     |
| SimpleRNN 25 / 100, Dropout 0.5                                       | 10 653 / 50 103 | 0.61 / 0.60 |
| SimpleRNN 50, Dropout 0.5 (**итоговая**)                              | 22 553     | 0.62     |
| SimpleRNN 50, только выход последнего шага                            | 7 703      | 0.54     |
| SimpleRNN 50, только выход последнего шага, `go_backwards=True`       | 7 703      | 0.63     |
| Bidirectional SimpleRNN 25                                            | 21 303     | 0.60     |

- Нормировка векторов слов повысила accuracy CNN с 0.63 до 0.67. Уменьшение сети и дропаут 0.5 (совет из лекции
  для борьбы с переобучением) сократили число параметров в 3,4 раза без потери точности.
- Для SimpleRNN число нейронов почти не влияет на результат, как и в примере из лекции.
- Если брать только выход последнего шага, точность падает до 0.54: документы дополнены нулями в конце, и к последнему
  шагу сеть «забывает» слова из начала (исчезающий градиент). Чтение с конца (`go_backwards`) решает проблему, как
  и описано в лекции.

## 6. Сравнение трех анализаторов

| Критерий                  | LSA (ПР2)                        | Word2Vec / Doc2Vec (ПР3)                 | CNN / SimpleRNN (ПР4)                         |
|---------------------------|----------------------------------|------------------------------------------|-----------------------------------------------|
| Представление документа   | Вектор тем из SVD матрицы TF-IDF | Среднее векторов слов / вектор документа | Последовательность векторов слов Word2Vec     |
| Порядок слов              | Не учитывается                   | Не учитывается                           | Учитывается (окно фильтра, память RNN)        |
| Обучение                  | Без учителя, тональность через LDA | Без учителя, тональность через LDA     | С учителем, сразу на метках тональности       |
| Accuracy на тесте         | 0.70                             | 0.68 / 0.67                              | 0.68 / 0.62                                   |
| Время обучения            | Около 3 с                        | Около минуты                             | Около 10 с (CNN) и 15 с (SimpleRNN)           |
| Поиск и сходство текстов  | Да                               | Да                                       | Нет, выход сети отражает только тональность   |

Выводы:

- CNN догнала лучшие анализаторы на векторах документов (0.68) и единственная из точных моделей учитывает порядок
  слов. Сверточный фильтр видит сочетания из трех соседних слов, а глобальная субдискретизация находит их в любом
  месте документа.
- SimpleRNN оказалась самой слабой (0.62) и дольше обучается. Это согласуется с лекцией: на длинных
  последовательностях простой рекуррентный слой страдает от исчезающего градиента, и результат «не намного лучше,
  если вообще лучше».
- Векторы, которые строят CNN и RNN, семантические только в контексте задачи обучения (тональности), поэтому для
  поиска похожих документов по содержанию по-прежнему нужны LSA и Doc2Vec из ПР2 и ПР3.
